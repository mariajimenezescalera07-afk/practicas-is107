HU8. Revisión y aprobación de solicitudes de registro

COMO administrador, QUIERO revisar y aprobar o rechazar las solicitudes de registro de los investigadores, PARA asegurar que solo los usuarios autorizados puedan acceder al sistema y realizar reservas.
El sistema debe permitir al administrador consultar las solicitudes de registro pendientes, revisar los datos aportados por cada investigador y decidir si la solicitud se aprueba o se rechaza.

Criterios de validación:
• El administrador puede visualizar todas las solicitudes de registro pendientes.
• El sistema muestra los datos identificativos del investigador y la información necesaria para comprobar su solicitud.
• El administrador puede aprobar una solicitud.
• El administrador puede rechazar una solicitud.
• Una solicitud aprobada permite al investigador quedar registrado como usuario validado.
• Una solicitud rechazada no permite al investigador realizar reservas.
• El sistema debe guardar el estado de la solicitud como aprobada o rechazada.

Discusión:
El administrador será el encargado de validar las solicitudes de registro tanto de investigadores de la UCO como de investigadores externos, asegurando que solo los usuarios previamente autorizados puedan utilizar las funciones de reserva del sistema.
