HU4. Investigadores y técnicos pueden poner incidencias

COMO investigador/técnico QUIERO poner incidencias desde la web parq que los equipos sean arreglados lo antes posible.
Al acceder al catálogo, cada equipo puede ser marcado como averiado. Esta incidencia es notificada a todos los técnicos, que pueden ver los equipos averiados en un apartado de la web, al que tienen acceso. Una vez se hayan reparado, deben eliminarlos de la lista de equipos averiados.

Validación:
Todos pueden poner incidencias, sean investigadores o técnicos.
Una vez el problema esté resuelto, deben volver a aparecer como disponibles.

Discusión:
Los investigadores NO tienen acceso al listado de dispositivos averiados, si lo están no pueden hacer la reserva.
Se debe incluir una pequeña descripción del problema para agilizar el trabajo.
